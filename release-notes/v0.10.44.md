# Azura Tools v0.10.44

## What's new since v0.10.39

- **Build Export:** Switching characters now updates the temporary **YOU** card as soon as the selected character loads, without requiring a map or channel change. Inspecting another player no longer replaces your character card. Inspected builds continue to appear separately in Saved Players.
- **Boss DPS:** Added the level 150 world boss **Grand Gobbler** to the encounter catalog. Its game ID is `WorldBossTurkey`; the displayed name is also recognized by Boss Skills. A synthetic encounter test passed; a live Grand Gobbler fight is still pending validation.
- **Launcher:** Added the new dragon and knight background artwork and corrected the footer height on large windows.

## Install or update

1. Download `AzuraTools-v0.10.44-win-x64.zip` below and extract the **entire** archive.
2. Run `azura-tools/AzuraTools.exe` from the extracted folder.
3. Install [Npcap](https://npcap.com/#download) for live capture. [AutoHotkey v1.1 64-bit](https://www.autohotkey.com/download/1.1/) is needed only for Hotkey Macro.

Settings, saved builds, and encounter history are stored in `%LOCALAPPDATA%\AzuraTools` and are not included in the ZIP. Node.js and Bun are not required.
