# Azura Tools v0.10.50

## What's new since v0.10.48

- **Safe Refine:** Updated detection for the game's new checkbox layout. The checkbox may move vertically as item details change, so Azura Tools now locates it near the captured position, reads its blue checked mark, and clicks its detected center. If its state cannot be confirmed, the automation stops before another Refine click.
- **Safe auto after a failed refine:** When Safe is unavailable at +9, the loop waits for it to become available again before the next attempt. If the item drops to +8, it checks Safe and confirms the mark before clicking Refine. If Safe does not reappear, the loop stops.
- Coordinates captured by older versions are cleared once. Capture the center of the **Safe Refine** checkbox and the **Refine** button again before starting the loop.

The user confirmed that Safe auto works in the compiled v0.10.50. All 165 automated tests passed, and all 554 files in the local application folder match the release ZIP by SHA-256.

## Install or update

1. Download `AzuraTools-v0.10.50-win-x64.zip` below and extract the **entire** archive.
2. Run `azura-tools/AzuraTools.exe` from the extracted folder.
3. Install [Npcap](https://npcap.com/#download) for live capture. [AutoHotkey v1.1 64-bit](https://www.autohotkey.com/download/1.1/) is needed only for Hotkey Macro.

Settings, saved builds, encounter history, and farm history stay in `%LOCALAPPDATA%\AzuraTools`; they are not included in the ZIP. Node.js and Bun are not required.
