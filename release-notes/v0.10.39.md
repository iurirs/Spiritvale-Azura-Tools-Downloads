# Azura Tools v0.10.39

## What's new since v0.10.27

- **Gold Dropped and Exp Acquired:** Two independent widgets show gains in the current map section, including totals and average rates per second and hour. Totals and rates use compact `k` and `m` units.
- **Build Export:** Your current character appears temporarily after its build loads in game, with Open in planner and Copy planner link actions. Restricted inspections are labeled **PARTIAL** and show only the gear the game exposes. Inspected player builds remain saved; your own build is kept only in memory.
- **SpiritVale update compatibility:** Restored inspection replies received through unresolved RPC links, updated local player identification, and adjusted combat decoding for the updated game client.
- **Boss Skills:** Recovered the cast duration for unresolved boss skill packets. Earthquake and Overload Fire were checked against a live Turtle Champion capture.
- **Personal DPS:** Corrected equal-value hit counting, synchronized the displayed rate with the last hit, and restarted an individual target's measurement when damage resumes after five seconds of inactivity. Its highest DPS and other targets remain independent.
- **Local build stability:** Fixed a login transition that removed the local Build Export card immediately after it appeared. The card and planner actions were confirmed in the live application after relogging.

## Install or update

1. Download `AzuraTools-v0.10.39-win-x64.zip` below and extract the **entire** archive.
2. Run `azura-tools/AzuraTools.exe` from the extracted folder.
3. Install [Npcap](https://npcap.com/#download) for live capture. [AutoHotkey v1.1 64-bit](https://www.autohotkey.com/download/1.1/) is needed only for Hotkey Macro.

Settings and encounter history remain in `%LOCALAPPDATA%\AzuraTools` when you replace an older extracted copy. No Node.js or Bun installation is needed.

## Validation and current limits

- All 148 automated tests passed. The 550 files in the local application folder and release ZIP were compared by SHA-256 before upload.
- Your local Build Export card was confirmed to stay visible for at least 15 seconds after login, with both planner actions available. Switching to a different character and opening the planner link in a browser have not yet been checked.
- Gold/EXP reward packets and map transitions still need a live in-game check. Some combat and death events after the game update also need broader in-game coverage.
- The temporary local build can remain visible briefly if you intentionally leave the character within ten seconds of loading it. It is never saved to the inspected-player database.
