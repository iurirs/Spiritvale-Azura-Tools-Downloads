## Instalar

1. Na página de releases, baixe `AzuraTools-v*-win-x64.zip`.
2. Extraia o ZIP inteiro e execute `azura-tools/AzuraTools.exe`.
3. Instale [Npcap](https://npcap.com/#download) para a captura em tempo real. O módulo Hotkey Macro também precisa de [AutoHotkey v1.1 64-bit](https://www.autohotkey.com/download/1.1/AutoHotkey_1.1.37.02_setup.exe).

O ZIP é portátil; não exige Node.js nem Bun no computador do jogador. Configurações e histórico ficam em `%LOCALAPPDATA%\AzuraTools`.

## Ferramentas

Boss Skills · Boss DPS/TPS/HPS · Personal DPS · Skill Reminder · Boss Elements · Build Export · Item Refine · Hotkey Macro.

Este repositório contém apenas informações de download e releases. O aplicativo verifica a release estável mais recente ao abrir e mostra um aviso quando há uma versão nova. A atualização é manual pelo ZIP.
