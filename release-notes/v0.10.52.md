# Azura Tools v0.10.52

## What's new since v0.10.50

- **Build Export:** Restored the temporary local character card and inspected builds after the latest SpiritVale update. Open inspections can be saved again; restricted inspections are shown as **Partial**. Older capture formats remain supported.
- **Boss DPS:** Updated player identity decoding for the current game format. Player names and classes are recovered from their spawn data and attached to the correct player IDs. A live diagnostic capture confirmed the previous `Player <ID>` issue across three boss encounters; replay of the updated decoder resolved six player identities. Please report any names that still appear as IDs in a new encounter.

All 166 automated tests passed. The 555 files in the application folder match the ZIP. The new Boss DPS overlay still needs confirmation in a fresh in-game encounter.

## Install or update

1. Download `AzuraTools-v0.10.52-win-x64.zip` below and extract the **entire** archive.
2. Run `azura-tools/AzuraTools.exe` from the extracted folder.
3. Install [Npcap](https://npcap.com/#download) for live capture. [AutoHotkey v1.1 64-bit](https://www.autohotkey.com/download/1.1/) is needed only for Hotkey Macro.

Settings, saved builds, encounter history, and farm history stay in `%LOCALAPPDATA%\AzuraTools`; they are not included in the ZIP. Node.js and Bun are not required.
