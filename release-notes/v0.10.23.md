# Azura Tools v0.10.23

This release replaces v0.10.22. It fixes invalid characters in three frontend files that prevented the Boss DPS interface from loading.

## What's new

The launcher now checks for the latest stable release on startup. When a newer version with a downloadable ZIP is available, it shows a notice linking to the release page. The check does not require a GitHub account, and the app does not install updates automatically.

## Install

Download `AzuraTools-v0.10.23-win-x64.zip`, extract the entire archive, and run `azura-tools/AzuraTools.exe`. Install [Npcap](https://npcap.com/#download) for live game data. Hotkey Macro also requires [AutoHotkey v1.1 64-bit](https://www.autohotkey.com/download/1.1/AutoHotkey_1.1.37.02_setup.exe).

Settings and encounter history remain in `%LOCALAPPDATA%\AzuraTools`.
