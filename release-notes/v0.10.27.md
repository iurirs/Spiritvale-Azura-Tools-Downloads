# Azura Tools v0.10.27

## What's new

- **Personal Death:** A separate overlay for up to three recent deaths of your character. It shows who killed you, the killing skill, fatal damage, and a 30-second countdown for each entry.
- **Personal Kill:** A separate overlay for up to three recent monsters you killed. It shows the monster, finishing skill, finishing hit damage, and an independent 30-second countdown.
- Both widgets can be enabled or disabled in Settings and positioned in the overlay editor. They are temporary and do not add to DPS history.
- Common monster names now use a 325-entry display catalog. For example, `NightmareScout` appears as **Echo Scout**. Boss names keep their established catalog labels.
- The ZIP includes third-party notices and the AGPL-3.0 license text for the bundled Spirit Vale Tools capture libraries.

## Install

1. Download `AzuraTools-v0.10.27-win-x64.zip` below and extract the entire archive.
2. Run `azura-tools/AzuraTools.exe` from the extracted folder.
3. Install [Npcap](https://npcap.com/#download) for live game capture. [AutoHotkey v1.1 64-bit](https://www.autohotkey.com/download/1.1/) is needed only for Hotkey Macro.

Settings and encounter history remain in `%LOCALAPPDATA%\AzuraTools` when replacing an older extracted copy.

## Validation and known limitation

- All 136 automated tests passed. The local application folder and ZIP were compared file by file before upload.
- Personal Death depends on receiving a decoded fatal-hit packet. In one diagnostic capture, the character's health reached zero without that packet, so that death could not be shown. This case remains under investigation; other deaths have appeared correctly.
